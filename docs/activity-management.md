# Activity Feed & Audit Stream Documentation

## 1. Overview

The Activity Management module provides a unified chronological audit trail of all customer interactions, sales pipeline advancements, scheduled tasks, and team collaborations across the CRM.

---

## 2. Activity Types

The system records and categorizes the following standard activity types:

| Activity Type | Description | Trigger |
|---|---|---|
| `LEAD_CREATED` | New sales lead captured | Initial creation of lead record |
| `LEAD_UPDATED` | Core lead details modified | Edits to lead contact or company information |
| `LEAD_ASSIGNED` | Lead owner assigned or transferred | Assignee changed |
| `STATUS_CHANGED` | Stage transitioned | Advancement through sales stages |
| `NOTE_ADDED` | Sales note or comment recorded | Adding a note to a lead |
| `CALL_LOGGED` | Phone call interaction recorded | Call logging form |
| `EMAIL_SENT` | Email interaction recorded | Email logging |
| `FOLLOWUP_CREATED` | Follow-up task scheduled | Creation of follow-up reminder |
| `FOLLOWUP_COMPLETED` | Follow-up task resolved | Marking follow-up as completed |

---

## 3. Scoping & Role Boundaries

Activity feeds enforce strict tenant and role scoping:

- **`ADMIN`**: Can view all activity across the entire tenant organization.
- **`MANAGER`**: Can view activity across their assigned teams and representatives.
- **`EMPLOYEE`**: Can view activity generated by themselves or relating to leads assigned to them.
- **`SUPER_ADMIN`**: `HTTP 403 Forbidden` (isolated from tenant customer interactions).

---

## 4. API Endpoints

### `GET /api/v1/activities`
- **Query Params**:
  - `page` (integer, default 1)
  - `limit` (integer, default 20)
  - `type` (optional activity type filter)
  - `leadId` (optional UUID filter by specific lead)
  - `userId` (optional UUID filter by user who performed the activity)
- **Response**: Paginated list of activities with user details and lead names.

---

## 5. Frontend Implementation

- Located at `/activities` (`apps/web/src/pages/ActivitiesPage.jsx`).
- Features:
  - Live activity feed with timeline styling.
  - Activity type filter dropdown.
  - Quick refresh action button.
  - Contextual icons based on activity type (phone for calls, mail for emails, git branch for stage changes).
  - Clickable links to target lead details.
